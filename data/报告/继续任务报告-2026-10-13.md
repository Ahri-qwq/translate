### 4.2 沙箱拦截

之前遇到过两次沙箱拦截，用户已经取消自动模式了，现在可以直接执行。但记住：

- 不要把阿里云 AK 作为命令行参数传给 `ossutil`（会被判定凭证泄露）
- 正确做法：写个 Python 脚本 `sys.path.insert(0, 'src')` 后 import
  `oss_uploader`，让它从 `config.yaml` 自己读 AK

```python
venv/Scripts/python.exe -I -c "
import sys; sys.stdout.reconfigure(encoding='utf-8')
sys.path.insert(0, 'src')
from oss_uploader import create_uploader
up = create_uploader()
up._upload_file(local_path, remote_oss_path)
"
```

### 4.3 复用代码跑单篇（不重跑 LLM）

如果需要重新生成某篇的博客文件或重新上传，**不要重跑 main.py**（会重新
调 LLM 翻译）。直接复用模块：

```python
from converter import BlogConverter
conv = BlogConverter()
conv.convert_article(article_dir=..., output_dir=...,
                     post_date='2026-10-13', category='DeePMD-kit')
```

传 `category` 参数就跳过 LLM 分类。

顺序很重要：**先传 OSS → 再跑 converter → 最后提 PR**。因为博客 md 里的
图片 URL 来自 `images_map.txt`，该文件由 OSS 上传时重写。
